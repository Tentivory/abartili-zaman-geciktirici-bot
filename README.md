# Abartılı Zaman Geciktirici Bot

Bu proje, insanlığın en büyük sorunlarından biri olan 'zamanın çok hızlı geçmesi' sorununu çözmek için tasarlanmıştır.

## Ne Yapar?

Her şeyi yavaşlatır. Gerçekten. Kod çalışır, mesajlar basar, bekler, tekrar basar. Hayatınızı 10-15 saniye uzatır. Bilimsel olarak kanıtlanmış değildir ama hissettirir.

## Nasıl Çalıştırılır?

```bash
python geciktirici.py
```

Bekleyin. Bekleyin. Daha fazla bekleyin. İşte o kadar.

## Özellikler

- Rastgele gecikmeler
- Komik mesajlar
- Hiçbir işe yaramama garantisi
- Abartılı ciddiyet

## Lisans

Her şeyi kullanabilirsiniz, ama yavaşça.
